### 測試步驟

1. 套用腳本
   - 遊戲開著：REDkit 的 **Tools → Debuggers → Reload scripts**
   - 遊戲沒開：開 `reference_level.w2w`，按 `Fast`（鏡頭先放到地面附近）
2. 主控台：`additem('gfg_ak47', 1, true)`；等級不夠時 `setlevel(31)`
3. 在**沒有敵人**的地方，對著牆測試

| 操作 | 預期 |
|---|---|
| 按住左鍵連射 | 鏡頭先往上、再左右擺，持續移動不停頓；準心一直在中央 |
| 看牆上的箭 | 插在準心附近 |
| 連射時往下拉滑鼠 | 可以把鏡頭壓住 |
| 放開左鍵 | 鏡頭轉回開槍前的位置 |
| 換彈中 | 準心還在 |
| 按 Shift 收槍，再按左鍵拿出 | 準心先消失，拿出後再出現 |
| （選做）用中鍵瞄準射一發 | 射完準心還在 |

要回報：鏡頭還會不會一頓一頓的、準心有沒有一直在、箭插在準心上還是偏到哪一邊
