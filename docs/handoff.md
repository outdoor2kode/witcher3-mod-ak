### 測試方式補充

- **騎馬左鍵（§24.4）**：在地面重載腳本（騎馬時重載可能卡住下馬鎖：§22.4）→ 叫馬、上馬 → 選用 AK → 左鍵
  - 預期：左鍵拿出 AK（不拔劍）、按住全自動、放開停火；有後座力、準心一直在；放開後 AK 不自動收
  - 拿著 AK 時馬可以加速、減速、跳；要下馬先按 C 收槍
  - 換彈：打完 30 發要能換彈、接著射（紀錄有 `horse: anim event OnWeaponReload -> AK`）
  - 中鍵（原版單發）射完，馬要能照常操作（紀錄有 `horse: ShootCrossbow -> idle`）
  - 第二次（§24.6）：輕點左鍵拿出後不會自己收、按 C 才收；換彈後也不收；後座力和地面差不多；子彈打在準心附近；滑鼠上下看要正常；馬上和地面各按幾次 Tab（紀錄 `radial: …`）
- 牆、建築、靶子：REDkit 編輯器直接放（`CLAUDE.md` §12，Wiki 頁面 15499265），或原版 `spawnPath`
- 遊戲開著時改腳本：REDkit 的 **Tools → Debuggers → Reload scripts**；**使用者沒按就不會套用**（2026-10-14 有一次忘了按）
- 遠處的怪物：`spawn('wolf', 1, 60, true)`（`CLAUDE.md` §12）
- 動畫圖（`.w2beh`）的狀態、切換條件：`python -X utf8 tools/cr2w_dump.py <檔案> --tree N --out <輸出>`，再用 awk 整理（做法見 `findings.md` §19.2、§20.6、§20.10）
