### 匯出紀錄的「Failed to get texture inputs」

- 每個貼圖參數都有一行：`Failed to get texture inputs for "g_t…": Only VCS file versions 59 through 71 are supported for variable 'vcsFileVersion': 72 (0x48)`
- 原因：Source 2 Viewer 20.0 只讀得懂 59～71 版的 shader 檔，CS2 現在的 shader 是 72 版
  - 20.0 原始碼 `ValveResourceFormat/CompiledShader/VfxProgramData.cs:573-583`（`earliest = 59`、`latest = 71`）
  - 開發中的版本（GitHub master，2026-10-14 查）已改成 58～72（同檔 `:544-554`）；正式版最新仍是 20.0（GitHub Releases：8 月 17 日）
- 匯出照樣完成：讀 shader 失敗就改用內建對照表 `BasicShaderDataProvider`
  - 20.0：`GltfModelExporter.Material.cs:397-414`（註解「Shaders are complicated, so do not stop exporting if they throw」）、`GltfModelExporter.cs:43`
  - `csgo_weapon` 的對照：`g_tColor` RGB = 顏色；`g_tMetalness` R = 粗糙度、G = 金屬度；`g_tAmbientOcclusion` R = AO（`ShaderDataProvider.cs:591-596`）
  - 表裡沒有的照名字猜，整張圖當一種：例 `g_tNormal` → `TextureNormal`（`ShaderDataProvider.cs:635-642`、`:667-670`）
- 結果：glTF 的三個材質都有顏色、法線、AO、粗糙度／金屬度貼圖（`weapon_rif_ak47.gltf` 各出現 3 次）
- 沒驗證：AK 的材質是不是用 `csgo_weapon` shader（是才套得上對照表）、猜出來的通道對不對 → 目視
- 需要更準時：等支援 72 版的正式版出來，再匯出一次

### REDkit 匯出／匯入流程（Wiki「HOW-TO: Use skinned meshes in Blender」，頁面 6326771，版本 1，含截圖）

- 匯出：Asset Browser 對實體模板按右鍵 → **Export Asset** → FBX（「a skinned model with textures and a skeleton」）
- Blender 匯入 FBX：Primary Bone Axis = **X**、Secondary Bone Axis = **Y**（截圖：Scale 1.00、Use Pre/Post Rotation 勾選、Manual Orientation 不勾）
- Blender 匯出 FBX：Primary = **X**、Secondary = **-Y**、Armature FBXNode Type = Null、勾 **Only Deform Bones**、不勾 Add Leaf Bones（截圖另有 Smoothing = Normals Only、Apply Modifiers 勾選）
- 匯回 REDkit：Asset Browser 背景按右鍵 → **Import > Mesh**
  - 對話框（`CFBXMeshImporter`）：`xmlMetadataLocation`、`importAsSkinnedMesh`（預設 false）、`generateCollisionIfMissing`（預設 false）
- 材質 XML：匯出蒙皮模型時，會在 FBX 旁邊產生；匯入時可用來指定材質與貼圖
  - 截圖範例（UTF-16）：`<mesh><mesh_data …><LODs><LOD_info distance="…"/></LODs></mesh_data><materials><material name="…" local="true" base="….w2mi"><param name="Diffuse" type="handle:ITexture" value="….xbm"/>…</material></materials></mesh>`
- Import 選單裡有 `2D Texture`（貼圖要另外匯入成 `.xbm`）
